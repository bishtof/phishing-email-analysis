# Phishing Email Analysis

## 📌 Project Overview
This project contains a structured analysis of a phishing email using a two-phase methodology:

1. Visual Analysis
2. Technical Analysis

The objective is to identify indicators of compromise (IOCs), social engineering techniques, and technical anomalies in the email headers and infrastructure.

---

## 📧 Email Subject
FINAL WARNING: Your Cloud Files Will Be Removed TODAY

---

## 🔍 Phase 1 – Visual Analysis

- Urgency language ("FINAL WARNING", "TODAY")
- Threat of account removal
- Generic branding
- Suspicious sender domain
- Emotional manipulation tactics

---

## 🛠 Phase 2 – Technical Analysis

- Sender: nooreply@zhf.xfougrvfzjzix.us
- Relay server: v-lanze.de
- Suspicious TLD (.us)
- Possible spoofed infrastructure
- SPF/DKIM to be verified

---

## 🚩 Indicators of Compromise (IOCs)

- Domain: zhf.xfougrvfzjzix.us
- Relay: v-lanze.de
- Subject pattern: FINAL WARNING

---

## 🧠 Conclusion

The email presents clear phishing characteristics including urgency manipulation, suspicious infrastructure, and potential spoofing attempts.
